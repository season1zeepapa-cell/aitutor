# DSG-EH-01 · 예외처리

> **단계** 설계 · **분류** 에러처리
> **출처** 소프트웨어 보안약점 진단가이드(2021) — 제3장 §3.1 (p.164–170)
> **연관 구현약점** [오류 메시지 정보노출 (IMP-EH-01)](./IMP-EH-01-error-message-info-exposure.md)

## 설계항목 / 설명

오류메시지에 중요정보(개인정보, 시스템 정보, 민감 정보 등)가 노출되거나, 부적절한 에러 및 오류처리로 인하여 의도치 않은 상황이 발생하지 않도록 설계한다.

## 보안대책

- ① 명시적인 예외는 **예외처리 블럭**으로 예외 발생시 수행 기능 구현
- ② 런타임 예외는 **입력값 범위 체크**로 정상 동작 값만 사용 보장
- ③ 에러 발생 시 **상세한 에러 정보가 사용자에게 노출되지 않도록** 설계

## 가. 취약점 개요

- **사례1(오류 메시지 정보노출)** — 별도 에러페이지 미설정 시 에러 메시지로 서버 데이터 정보 등 공격에 필요한 정보가 노출
- **사례2(시스템 정보노출)** — 시스템·관리자·DB정보 등 내부 데이터 공개 시 공격자에게 또 다른 공격의 빌미 제공

## 나. 설계 시 고려사항

1. **명시적 예외처리 블럭** — 언어별 예외처리 문법의 안전한 사용방법을 기술하고 시큐어코딩 규칙 정의. (예시: Java Logger API로 에러 정보 로깅)
2. **런타임 예외 입력값 범위 체크** — 입력값에 따라 예외 발생 가능 시 입력값 범위를 체크하도록 시큐어코딩 규칙 정의
3. **상세 에러정보 비노출**
   - (ㄱ) 에러 발생 시 지정된 에러페이지로 리다이렉트되도록 시큐어코딩 규칙 정의, 또는 WAS 설정으로 지정 페이지 응답 (예: web.xml `error-page`로 404/500/Throwable별 페이지)
   - (ㄴ) 사용자에게 보내는 오류 메시지에 중요정보(개인정보·시스템정보·민감정보) 미포함하도록 시큐어코딩 규칙 정의

## 다. 진단 세부사항 (요구사항별 체크리스트)

> 📋 각 진단방법은 **관련산출물 검토예시**와 짝을 이룬다 — 이것이 복합서술형(진단보고서) 채점 기준이 된다.

### 요구사항 ① 명시적 예외처리
- **Q1. 명시적인 Exception 상황을 안전하게 처리하도록 설계되어 있는가?**
  - `1-1` 요구사항정의서·아키텍처설계서·요구사항추적표
  - `1-2` Exception 유형별 처리 방법 + 안전한 처리(시스템정보 비노출·반드시 처리·예외 상황별 분리 처리)를 개발가이드에 정의 → **유즈케이스설계서·클래스설계서·개발가이드**
  - `1-3` Exception 로깅 정책(시간·이유 포함, 로그 내 중요정보 암호화) 설계 반영 → **아키텍처설계서**
- **Q2. 안전한 예외처리 점검 테스트계획이 수립되어 있는가?**
  - `2-1` 예외 가능 입력값으로 안전 처리 점검 테스트 계획 → **단위테스트계획서**

### 요구사항 ② 런타임 예외 입력값 범위 체크
- **Q1. Runtime Exception이 안전하게 처리되도록 설계되어 있는가?**
  - `1-1` 요구사항정의서·아키텍처설계서·요구사항추적표
  - `1-2` 유효 입력값 범위 검증으로 예외 미발생하도록 개발가이드 코딩 규칙 정의 → **개발가이드**
- **Q2. 안전한 예외처리 점검 테스트계획이 수립되어 있는가?**
  - `2-1` 예외 가능 입력값으로 예외 상황 안전 처리 점검 → **단위테스트계획서**

### 요구사항 ③ 상세 에러정보 비노출
- **Q1. Exception 발생 시 상세 에러정보가 사용자에게 노출되지 않도록 설계되어 있는가?**
  - `1-1` 요구사항정의서·아키텍처설계서·요구사항추적표
  - `1-2` 스택정보·중요정보 외부 비노출 개발가이드 코딩 규칙 → **개발가이드**
  - `1-3` 지정된 에러페이지로 예외사항 정보 제공 서버설정 계획 → **요구사항정의서·아키텍처설계서**
  - `1-4` Exception 발생 로그 생성 서버설정 계획 → **요구사항정의서·아키텍처설계서**
- **Q2. 에러로 상세정보 노출 점검 테스트 계획이 수립되어 있는가?**
  - `2-1` 상세 예외사항·시스템 중요정보 노출 여부 점검 → **단위테스트계획서**
