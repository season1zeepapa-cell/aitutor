# DSG-SF-08 · 중요정보 전송

> **단계** 설계 · **분류** 보안기능
> **출처** 소프트웨어 보안약점 진단가이드(2021) — 제3장 §2.8 (p.159–163)
> **연관 구현약점** [암호화되지 않은 중요정보 (IMP-SF-05)](./IMP-SF-05-unencrypted-sensitive-info.md)

## 설계항목 / 설명

중요정보(비밀번호, 개인정보, 쿠키 등)를 전송하는 방법이 안전하도록 설계한다.

## 보안대책

- ① 인증정보와 같은 민감한 정보 전송시 **안전하게 암호화**해서 전송
- ② 쿠키에 포함되는 중요정보는 **암호화**해서 전송

## 가. 취약점 개요

프로그램이 보안과 관련된 민감한 데이터를 평문으로 송·수신할 경우, 통신채널 스니핑으로 인가되지 않은 사용자에게 민감한 데이터가 노출될 수 있다.

## 나. 설계 시 고려사항

1. **민감한 정보 암호화 전송** — 분석단계에서 정의된 중요정보를 네트워크로 전송할 때 안전한 암호모듈로 암호화하거나 안전한 통신 채널을 사용. 안전한 암호화는 "암호연산" 설계항목을 충족하는 알고리즘·키 사용. 클라이언트↔서버 전달 데이터(hidden필드·Ajax변수·쿠키·헤더·HTTP 응답헤더 등) 중 불필요하게 많은 데이터가 전송되지 않도록 설계
2. **쿠키 내 중요정보 암호화** — 쿠키에 중요정보를 포함하지 않는 것이 원칙. 부득이한 경우 반드시 **세션쿠키**로 설정하고 전달 중요정보는 반드시 암호화

## 다. 진단 세부사항 (요구사항별 체크리스트)

> 📋 각 진단방법은 **관련산출물 검토예시**와 짝을 이룬다 — 이것이 복합서술형(진단보고서) 채점 기준이 된다.

### 요구사항 ① 민감한 정보 암호화 전송
중요정보를 네트워크로 외부와 송·수신하는 경우 데이터 암호화 또는 통신 구간 암호화를 수행하도록 명시하고 있는지 확인한다.

- **Q1. 민감한 정보를 전송할 때 안전하게 암호화해서 전송되도록 설계되어 있는가?**
  - `1-1` 요구사항정의서 대책 + 아키텍처설계서 적용계획 + 요구사항추적표 추적 → **요구사항정의서·요구사항추적표·아키텍처설계서**
  - `1-2` 암호화 대상 중요정보 분류 여부(개인정보보호법: 고유식별정보·바이오정보·비밀번호 / 정보통신망법: 주민등록번호·신용카드번호·계좌번호 / 위치정보법: 위치정보 / 시스템 중요정보: DB·연동시스템 계정·주요 설정) → **요구사항정의서·아키텍처설계서**
  - `1-3` 안전한 암호화 정책(TLSv2, VPN 등)이 적용된 암호화 통신 구간 사용 → **아키텍처설계서**
  - `1-4` 통신 구간 암호화 미사용 시 안전한 암호 알고리즘으로 암호화 전송 → **프로그램명세서·유즈케이스설계서·클래스설계서·개발가이드**
- **Q2. 네트워크 전송 중요정보의 암호화 여부 점검 테스트 계획이 수립되어 있는가?**
  - `2-1` 패킷 스니핑 등으로 중요정보 노출 여부 점검 테스트 계획 → **단위테스트계획서**

### 요구사항 ② 쿠키 내 중요정보 암호화
쿠키에 포함되는 중요정보를 식별하고 암호화하도록 명시하고 있는지 확인한다.

- **Q1. 쿠키 내 중요정보가 암호화되어 전송되도록 설계되어 있는가?**
  - `1-1` 요구사항정의서·아키텍처설계서·요구사항추적표
  - `1-2` 암호화 대상 중요정보 분류 여부 → **요구사항정의서·아키텍처설계서**
  - `1-3` 쿠키 전송용 안전한 암호화 정책(TLSv2, VPN) 적용 통신 구간 → **아키텍처설계서**
  - `1-4` 통신 구간 미사용 시 안전한 암호 알고리즘 암호화 전송 → **프로그램명세서·유즈케이스설계서·클래스설계서·개발가이드**
- **Q2. 쿠키 내 중요정보 암호화 적용 테스트 계획이 있는가?**
  - `2-1` 패킷 스니핑 등으로 쿠키 내 중요정보 노출 여부 점검 → **단위테스트계획서**
