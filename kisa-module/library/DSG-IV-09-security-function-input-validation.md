# DSG-IV-09 · 보안기능 입력값 검증

> **단계** 설계 · **분류** 입력데이터 검증 및 표현
> **출처** 소프트웨어 보안약점 진단가이드(2021) — 제3장 §1.9 (p.86–92)
> **연관 구현약점** [보안기능 결정에 사용되는 부적절한 입력값 (IMP-IV-15)](./IMP-IV-15-security-decision-improper-input.md) · [정수형 오버플로우 (IMP-IV-14)](./IMP-IV-14-integer-overflow.md) · Null Pointer 역참조

## 설계항목 / 설명

보안기능(인증, 권한부여 등) 입력 값과 함수(또는 메소드)의 외부입력값 및 수행 결과에 대한 유효성 검증방법 설계 및 유효하지 않은 값에 대한 처리방법을 설계해야 한다.

## 보안대책

- ① 사용자의 역할, 권한을 결정하는 정보는 **서버에서 관리**
- ② 쿠키값·환경변수·파라미터 등 외부입력값이 보안기능 함수의 인자로 사용되는 경우, **검증작업 후 제한적으로 사용**
- ③ 중요상태정보·인증·권한 결정 정보는 **쿠키로 전송 금지**, 불가피 시 **암호화** 전송

## 가. 취약점 개요

- **사례1 보안기능 결정에 사용되는 부적절한 입력값** — 쿠키·환경변수·파라미터를 검증 없이 사용하면 권한·역할 변수를 조작해 상승된 권한으로 작업 수행
- **사례2 정수형 오버플로우** — 정수가 허용 최댓값을 초과해 아주 작은 수·음수가 됨. 반복문 제어·메모리 할당·복사 조건에 쓰이면 보안문제 유발
- **사례3 Null Pointer 역참조** — 객체가 널이 될 수 없다는 가정 위반 시 발생, 예외 상황을 추후 공격에 이용

## 나. 설계 시 고려사항

1. **역할·권한 정보의 서버 관리** — 상태·인증·인가·권한 중요정보는 서버 측 세션이나 DB에 저장
2. **외부입력값 검증 후 제한적 사용** — 보안기능 함수는 외부입력값 의존이 없는 구조로 설계. 불가피 시 검증 후 제한적 사용. 클라이언트·서버 검증방식 동일. 사용 전 NULL 여부 체크
3. **중요정보 쿠키 전송 금지·암호화** — 중요정보 쿠키는 암호화 전송하거나 HMAC 등 메시지인증코드로 서버측 무결성 검증

## 다. 진단 세부사항 (요구사항별 체크리스트)

> 📋 각 진단방법은 **관련산출물 검토예시**와 짝을 이룬다 — 이것이 복합서술형(진단보고서) 채점 기준이 된다.

### 요구사항 ① 역할·권한 정보의 서버 관리
- **Q1. 사용자의 역할 및 권한 결정을 서버에서 관리하는 정보로 서버에서 처리하도록 설계되어 있는가?**
  - `1-1` 요구사항정의서·아키텍처설계서·요구사항추적표
  - `1-2` 사용자 역할 구분(일반/관리자/최고관리자 등) → **클래스설계서·DB설계서**
  - `1-3` 각 역할별 권한 구분 → **클래스설계서·DB설계서**
  - `1-4` 역할·권한 저장 DB 설계 → **DB설계서**
  - `1-5` 역할·권한 검증 모듈 설계 또는 외부 라이브러리 사용 시 검증 정보가 DB·세션 저장 → **클래스설계서·유즈케이스설계서**
- **Q2. 인증우회 및 권한상승 점검 테스트 계획이 수립되어 있는가?**
  - `2-1` 조작된 파라미터·쿠키로 역할·권한 체크 우회 점검 테스트 계획 → **단위테스트케이스**

### 요구사항 ② 외부입력값 검증 후 제한적 사용
- **Q1. 보안기능 수행에 사용되는 입력값이 안전하게 사용되도록 설계되어 있는가?**
  - `1-1` 요구사항정의서·아키텍처설계서·요구사항추적표
  - `1-2` 보안기능 사용 값의 종류·출처·의미 정의 → **유즈케이스설계서·클래스설계서**
  - `1-3` 외부 입력값 사용 시 타당한 근거/사유 명시 → **유즈케이스설계서·클래스설계서**
  - `1-4` 외부 입력값 검증 방법 정의(NULL 검사, 정수오버플로우 등 범위 초과 점검 후 사용) → **개발가이드**
- **Q2. 외부 입력값 조작으로 보안기능 우회 점검 테스트 계획이 수립되어 있는가?**
  - `2-1` 외부입력값 조작으로 보안기능 무력화·오작동 여부 점검 테스트 계획 → **단위테스트케이스**

### 요구사항 ③ 중요정보 쿠키 전송 금지·암호화
- **Q1. 쿠키로 전달되는 정보가 분류되고, 불가피하게 전송되는 중요정보가 안전하게 전달되도록 설계되어 있는가?**
  - `1-1` 요구사항정의서·아키텍처설계서·요구사항추적표
  - `1-2` 쿠키 포함 정보의 이름·값·의미·유효기간 정의(중요정보 포함 시 근거/사유 명시) → **유즈케이스명세서·클래스설계서**
  - `1-3` 중요정보 쿠키 암호화 처리 방식 설계(암호화 통신채널 전송 속성, 안전한 암호알고리즘 암호화) → **유즈케이스명세서·클래스설계서**
  - `1-4` 쿠키 중요정보의 무결성 검사 방법·모듈 설계 → **유즈케이스명세서·클래스설계서**
- **Q2. 쿠키 조작으로 중요정보 탈취·변조 점검 테스트 계획이 수립되어 있는가?**
  - `2-1` 쿠키값 복호화·변조 전달로 정보 조작 가능 여부 점검 테스트 계획 → **단위테스트케이스**
