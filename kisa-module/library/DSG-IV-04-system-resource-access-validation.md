# DSG-IV-04 · 시스템 자원 접근 및 명령어 수행 입력값 검증

> **단계** 설계 · **분류** 입력데이터 검증 및 표현
> **출처** 소프트웨어 보안약점 진단가이드(2021) — 제3장 §1.4 (p.58–63)
> **연관 구현약점** [코드 삽입 (IMP-IV-02)](./IMP-IV-02-code-injection.md) · [경로 조작 및 자원 삽입 (IMP-IV-03)](./IMP-IV-03-path-resource-injection.md) · 서버사이드 요청 위조 · [운영체제 명령어 삽입 (IMP-IV-05)](./IMP-IV-05-os-command-injection.md)

## 설계항목 / 설명

시스템 자원접근 및 명령어를 수행할 때 입력값에 대한 유효성 검증방법 설계 및 유효하지 않은 값에 대한 처리방법을 설계해야 한다.

## 보안대책

- ① 외부입력값으로 시스템자원(IP, PORT번호, 프로세스, 메모리, 파일 등)을 식별하는 경우 **허가되지 않은 자원이 사용되지 않도록** 설계
- ② 서버프로그램 안에서 셸을 생성해 명령어를 실행해야 하는 경우 **악의적인 명령어가 실행되지 않도록** 설계

## 가. 취약점 개요

- **사례1 경로 조작 및 자원 삽입** — 입력값 조작으로 보호 자원에 임의 접근하여 수정·삭제, 정보누출, 자원 충돌에 의한 서비스 장애 유발
- **사례2 허가되지 않은 명령 실행** — 검증 없는 입력값으로 의도하지 않은 시스템 명령어가 실행되어 권한 변경·시스템 운영 악영향

## 나. 설계 시 고려사항

1. **시스템자원 식별 - 허가된 자원만 사용** — 외부입력값이 리소스를 직접 결정하지 않도록 설계. 리소스 목록을 프로퍼티/XML 파일로 정의해 지정 범위 내에서 선택. 디렉토리 전체 파일처럼 목록화가 어려우면 경로조작 문자(`.. / \`)를 제거하고 지정 경로 내 파일만 접근하도록 시큐어코딩 규칙 정의
2. **셸 명령어 실행 - 악의적 명령어 차단** — 셸 생성·명령 실행 구조를 가지지 않는 설계가 우선. 불가피하면 외부입력값을 명령어 일부로 직접 쓰지 않고, 허용목록 내 값으로만 명령어를 조립. 허용목록은 프로퍼티/XML 파일로 작성하고, 외부입력값은 목록 검색용 **인덱스값**으로만 사용해 명령어 사용 최소화

## 다. 진단 세부사항 (요구사항별 체크리스트)

> 📋 각 진단방법은 **관련산출물 검토예시**와 짝을 이룬다 — 이것이 복합서술형(진단보고서) 채점 기준이 된다.

### 요구사항 ① 시스템자원 식별 - 허가된 자원만 접근
- **Q1. 외부입력값이 시스템자원 식별값으로 쓰일 때, 허가된 자원에만 접근하도록 보안설계가 적용되어 있는가?**
  - `1-1` 요구사항정의서 대책 + 아키텍처설계서 적용계획 + 요구사항추적표 추적 → **요구사항정의서·요구사항추적표·아키텍처설계서**
  - `1-2` 허가된 자원이 식별·기능과 매핑 → **아키텍처설계서 보안요구항목·DB설계서(자원-기능 매핑)**
  - `1-3` 자원 접근 이력 로그 설계(시간·사용자ID·IP·입력값, 권한없는 접근 포함) → **아키텍처설계서·유즈케이스설계서·클래스설계서**
- **Q2. 허가되지 않은 자원 접근 점검 테스트 계획이 수립되어 있는가?**
  - `2-1` 조작 입력으로 미허가 자원(파일·서비스·프로세스·데이터) 접근 점검(`.. / \` 등) → **단위테스트케이스**

### 요구사항 ② 셸 명령어 실행 - 허가된 명령만 실행
- **Q1. 외부입력값이 OS 명령어/파라미터로 쓰일 때, 허가된 명령만 실행되도록 보안설계가 적용되어 있는가?**
  - `1-1` 요구사항정의서·아키텍처설계서·요구사항추적표
  - `1-2` 명령어 실행 기능 식별 + 실행 가능 명령어/파라미터 제한 설계 → **아키텍처설계서·클래스설계서·유즈케이스설계서**
  - `1-3` OS 명령어 실행 이력 로그 설계(시간·사용자ID·IP·입력값·실행 명령어·파라미터) → **아키텍처설계서 보안요구항목·클래스설계서(로깅 설계)·개발가이드(로깅 코딩규칙)**
- **Q2. 허가되지 않은 명령어 실행가능 여부 점검 계획이 수립되어 있는가?**
  - `2-1` 조작 입력으로 미허가 명령어 실행가능 여부 테스트(검증 문자열 `| & ;` 등 정의 + 예상 결과) → **단위테스트케이스**
