# DSG-IV-05 · 웹 서비스 요청 및 결과 검증

> **단계** 설계 · **분류** 입력데이터 검증 및 표현
> **출처** 소프트웨어 보안약점 진단가이드(2021) — 제3장 §1.5 (p.64–70)
> **연관 구현약점** [크로스사이트 스크립트 (IMP-IV-04)](./IMP-IV-04-xss.md)

## 설계항목 / 설명

웹 서비스(게시판 등) 요청(스크립트 게시 등)과 응답결과(스크립트를 포함한 웹 페이지)에 대한 유효성 검증방법 설계 및 유효하지 않은 값에 대한 처리방법을 설계해야 한다.

## 보안대책

- ① 사용자 입력값을 동적 응답페이지에 사용하는 경우 **XSS 필터링** 수행 후 사용
- ② DB조회결과를 동적 응답페이지에 사용하는 경우 **HTML인코딩 또는 XSS 필터링** 수행 후 사용

## 가. 취약점 개요

- **사례1 Reflective XSS** — 외부 입력값을 검증 없이 응답페이지 생성에 사용 → 접속자 권한으로 부적절한 스크립트 실행, 정보 유출
- **사례2 Stored XSS** — 공격자가 악성 스크립트를 미리 저장 → 일반 사용자 조회 시 접속자 권한으로 스크립트 수행, 정보 유출

## 나. 설계 시 고려사항

1. **입력값에 대한 XSS 필터링** — 필터링/인코딩 정책 공통코드를 웹 컨테이너·MVC 프레임워크에 적용
   - (ㄱ) Filter 컴포넌트로 입력값에 XSS필터·HTML인코딩을 적용해 안전한 값으로 치환, 모든 애플리케이션에 일괄 적용
   - (ㄴ) MVC Interceptor 컴포넌트로 XSS 공격 패턴 검사 후 요청 차단·허용, 일괄 적용
   - (ㄷ) 공통 Validator 컴포넌트로 XSS 공격패턴 입력값 필터링
2. **DB조회결과에 대한 XSS 필터링/HTML인코딩** — 각 컴포넌트에서 출력값에 XSS필터·HTML인코딩 적용
   - (ㄱ) View 컴포넌트에서 출력값 HTML인코딩 적용하도록 시큐어코딩 규칙 정의
   - (ㄴ) **DB에서 읽어온 값도 외부 입력값 범위에 포함**시켜 출력 전 검증. 일괄 필터링이 어려우면 개발자가 출력값 검증, 라이브러리(ASP.NET: MS Anti-XSS·AntiXSSEncoder·HTML Sanitizer / Java: LUCY XSS Filter·OWASP ESAPI / PHP: HTML Purifier) 사용 고려

## 다. 진단 세부사항 (요구사항별 체크리스트)

> 📋 각 진단방법은 **관련산출물 검토예시**와 짝을 이룬다 — 이것이 복합서술형(진단보고서) 채점 기준이 된다.

### 요구사항 ① 입력값 XSS 필터링
- **Q1. 외부입력값의 XSS 공격코드를 안전하게 필터링하도록 보안설계가 적용되어 있는가?**
  - `1-1` 요구사항정의서 대책 + 아키텍처설계서 적용계획 + 요구사항추적표 추적 → **요구사항정의서·요구사항추적표·아키텍처설계서**
  - `1-2` XSS 필터 컴포넌트 설계(외부라이브러리 안전성, 화이트리스트 정책) → **프로그램명세서·클래스설계서·유즈케이스설계서·아키텍처설계서 보안요구항목**
  - `1-3` XSS 필터링 방법 정의(Filter 적용대상 웹서버 설정파일, 개별 프로그램 입력·출력 필터링 코딩규칙) → **아키텍처설계서·개발가이드**
- **Q2. 입력값 XSS필터링 점검 테스트 계획이 수립되어 있는가?**
  - `2-1` 필터 우회 입력값(`<IMG SRC="javascript:alert('XSS');">` 등, OWASP XSS Filter Evasion Cheat Sheet 참조) 점검 → **단위테스트케이스**

### 요구사항 ② DB조회결과 XSS 필터링/HTML인코딩
- **Q1. DB조회 결과의 XSS 공격코드를 안전하게 필터링하도록 보안설계가 적용되어 있는가?**
  - `1-1` 요구사항정의서·아키텍처설계서·요구사항추적표
  - `1-2` XSS 필터 컴포넌트 설계(외부라이브러리 안전성, 화이트리스트 정책) → **아키텍처설계서 보안요구항목·프로그램명세서·클래스설계서·유즈케이스설계서**
  - `1-3` DB조회결과 응답페이지 생성 시 XSS필터·HTML인코딩 코딩규칙 정의 → **아키텍처설계서·개발가이드**
- **Q2. DB조회 결과 XSS필터링 점검 테스트 계획이 수립되어 있는가?**
  - `2-1` DB조회 결과값에 XSS필터링 적용으로 안전한 값만 응답 사용되는지 점검 → **단위테스트케이스**
