# DSG-IV-03 · 디렉토리 서비스 조회 및 결과 검증

> **단계** 설계 · **분류** 입력데이터 검증 및 표현
> **출처** 소프트웨어 보안약점 진단가이드(2021) — 제3장 §1.3 (p.54–57)
> **연관 구현약점** [LDAP 삽입 (IMP-IV-10)](./IMP-IV-10-ldap-injection.md)

## 설계항목 / 설명

디렉토리 서비스(LDAP 등)를 조회할 때 입력값과 그 조회결과에 대한 유효성 검증방법 설계 및 유효하지 않은 값에 대한 처리방법을 설계한다.

## 보안대책

- ① LDAP 인증서버로 인증을 구현하는 경우 인증요청에 사용되는 외부입력값은 **LDAP 삽입 취약점을 가지지 않도록 필터링**해서 사용

## 가. 취약점 개요

외부입력값이 LDAP 조회를 위한 필터 생성에 사용될 때 필터규칙을 변경할 수 있는 입력값을 검증하지 않으면, 공격자가 의도하는 LDAP 조회가 수행될 수 있다. (LDAP: TCP/IP 위에서 디렉토리 서비스를 조회·수정하는 응용 프로토콜)

## 나. 설계 시 고려사항

1. **LDAP 검색 필터 특수문자 필터링** — 외부입력값이 LDAP 검색 필터 생성에 삽입될 때, 필터 규칙으로 인식 가능한 특수문자(`= + < > # ; \`)를 제거하고 사용하도록 시큐어코딩 규칙 정의
   - 활용 가능한 프레임워크/라이브러리(Java·PHP·ASP): LDAP Syntax Filters — 액티브 디렉토리 검색기준 정의, MS 웹문서·참조목록의 필터 작성 문법을 참고하여 특수문자 필터링

## 다. 진단 세부사항 (요구사항별 체크리스트)

> 📋 각 진단방법은 **관련산출물 검토예시**와 짝을 이룬다 — 이것이 복합서술형(진단보고서) 채점 기준이 된다.

### 요구사항 ① LDAP 삽입 방지 필터링
- **Q1. 외부입력값이 LDAP조회 필터생성에 삽입될 때, 안전하게 사용되도록 보안설계가 적용되어 있는가?**
  - `1-1` 요구사항정의서 대책 + 아키텍처설계서 적용계획 + 요구사항추적표 추적 → **요구사항정의서·요구사항추적표·아키텍처설계서**
  - `1-2` LDAP 조회필터 입력값 필터링 기능 설계 또는 안전한 외부라이브러리 사용 → **프로그램명세서·컴포넌트설계서·유즈케이스설계서·클래스설계서**
  - `1-3` LDAP필터링 코딩규칙이 개발가이드에 정의 → **개발가이드**
- **Q2. LDAP 삽입 취약점 점검 테스트 계획이 수립되어 있는가?**
  - `2-1` LDAP 필터구문 변경 입력값(`= + < > # ; \` 등)으로 필터 규칙 변경 점검 → **단위테스트케이스**
