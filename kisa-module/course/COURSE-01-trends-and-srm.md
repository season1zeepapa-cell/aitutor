# COURSE-01 · Ⅰ. SW개발보안의 최신 동향과 이해

> **유형** 교육자료 (양성과정 교재) · **출처** 2025년 SW보안약점 진단원 기본(양성)과정 (p.5–36)

## 개요

최신 사이버 위협 동향·사고 사례로 SW개발보안의 필요성을 이해하고, **보안위험관리(SRM)**의 핵심 개념을 학습한다.

## 1. SW보안 사고 사례 / 위협 트렌드

- 공격자의 **생성형 AI 활용 본격화** (FraudGPT·WormGPT, 딥페이크 협박)
- 2025년 국내 주요 사고: **SK텔레콤 인증서버(HSS) 침해 → 유심 정보(IMSI·KI) 유출**, 심스와핑 위험
- **제로클릭 공격** 등 은밀한 공격 증가

> 📌 시험: 보안 필요성·배경 이해 문항으로 출제 가능

## 2. SRM(보안위험관리) – 위험 구성요소

| 요소 | 정의 |
|------|------|
| **정보자산(Asset)** | 정보·데이터, HW, SW, 물리환경, 인적자산. 보안등급 = **CIA** |
| **위협(Threat)** | 취약성에 영향을 주어 악영향을 끼치는 사건/행위 (STRIDE) |
| **취약점(Vulnerability)** | 위협 발생의 전제조건, 자산의 보안 결점 |

**STRIDE 위협 모델 ↔ 대응**
| 위협 | 대응 |
|------|------|
| Spoofing | 인증(Authentication) |
| Tampering | 무결성(Integrity) |
| Repudiation | 부인봉쇄(Non-repudiation) |
| Information Disclosure | 기밀성(Confidentiality) |
| DoS | 가용성(Availability) |

## 3. 위험평가 · 위험처리 · 정보보호대책 · 위험관리

- **위험평가**: 자산·위협·취약성의 **상호작용**(V×A×T)으로 평가 — 단순 산술합 아님
- **위험처리 전략**: 위험감소(취약점 제거·방화벽, 가장 보편적)·위험수용 — 발생가능성·영향도 고려
- **정보보호대책**: 관리적(정책·교육)·기술적(암호화·방화벽·IDS)·물리적(출입통제·CCTV) → **통합 적용**
- **위험관리**: 식별 → 분석 → 평가 → 대응 (위험분석+위험평가+대응 전체)

## 🎯 시험 출제 포인트

1. 정보자산 보안등급 = 기밀성+무결성+가용성(CIA)
2. STRIDE 위협 ↔ 대응(인증/무결성/부인봉쇄/기밀성/가용성) 매핑
3. 위험 = 자산 × 위협 × 취약성 (상호작용, 산술합 아님)
4. 정보보호대책 3분류: 관리적·기술적·물리적
5. 위험처리: 위험감소 전략이 가장 보편적
