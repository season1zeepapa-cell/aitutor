# HTTP 프로토콜 유효성 검증 (COURSE-DSG-IV-07)

> Ⅳ. 분석·설계 단계 보안약점 진단 · 2025년 SW보안약점 진단원 기본(양성)과정 · pp.141-146
> 관련 라이브러리: DSG-IV-07 · 분류: 입력데이터 검증 및 표현

## 개요

비정상적인 HTTP 헤더, 자동연결 URL 링크 등 **사용자가 원하지 않은 결과를 생성할 수 있는 HTTP 헤더 및 응답결과**에 대한 유효성 검증방법과 유효하지 않은 값에 대한 처리방법을 설계한다.

- 외부입력값을 쿠키·HTTP 헤더정보로 사용하는 경우 **HTTP 응답분할** 취약점을 가지지 않도록 필터링해서 사용
- 외부입력값이 페이지 이동(리다이렉트/포워드) URL로 사용되어야 하는 경우, 해당 값은 **시스템에서 허용된 URL 목록의 선택자**로 사용
- 관련 보안약점: 입력데이터 검증 및 표현 > **HTTP 응답분할**, **신뢰되지 않는 URL주소로 자동접속 연결(오픈 리다이렉트)**

## 설계 시 고려사항

**외부입력값을 쿠키·HTTP 헤더정보로 사용하는 경우 HTTP 응답분할 취약점을 가지지 않도록 필터링한다.**

- `\r\n` 문자는 HTTP 응답에서 헤더와 바디를 구분하는 구분자이므로, 응답헤더에 삽입되는 외부입력값은 반드시 `\r\n`(CR, LF)을 제거하고 사용하도록 시큐어코딩 규칙을 정의한다.
- 헤더에 값을 삽입하는 경우(Cookie 값 설정, 응답헤더 값 설정, 리다이렉트 Location 삽입)에 응답분할을 일으킬 수 있는 문자(`\r\n`)를 필터링하는 검증 절차를 적용한다.

**외부입력값이 페이지 이동 URL로 사용되어야 하는 경우, 허용된 URL 목록의 선택자로 사용한다.**

- 페이지 이동을 허용하는 URL 목록을 소스코드에 하드코딩하거나 설정파일(XML, properties)에 저장하여 허용된 URL로만 이동할 수 있도록 설계한다.

## 진단 기준 및 방법

### 요구사항 01 — HTTP 응답분할 방지 (쿠키/헤더 외부입력값 필터링)

**진단항목 01. HTTP 응답분할이 발생하지 않도록 입력값 검증을 수행하도록 설계되어 있는가?**

| 진단방법 | 관련 산출물 |
|---|---|
| 1-1 요구사항정의서 대책 + 아키텍처설계서 적용계획 + 요구사항추적표 추적 가능 여부 | 요구사항정의서, 요구사항추적표, 아키텍처설계서 |
| 1-2 응답헤더에 값을 쓰는 기능 식별 + 개행문자 필터링 기능 설계 (함수 예: setHeader, addCookie, sendRedirect / 개행문자: CR(\r), LF(\n)) | 프로그램명세서, 클래스설계서, 아키텍처설계서 |
| 1-3 개행문자 필터링 적용방법 — 필터 컴포넌트 공통 적용 또는 각 기능 코딩규칙 정의 | 아키텍처설계서, 개발가이드 |

**진단항목 02. HTTP 응답분할 취약점을 점검하는 테스트 계획이 수립되어 있는가?**

| 진단방법 | 관련 산출물 |
|---|---|
| 2-1 CR(\r)·LF(\n) 포함 입력값으로 응답분할 발생 여부 점검 | 단위테스트케이스 |

### 요구사항 02 — 오픈 리다이렉트 방지 (페이지 이동 URL 허용목록)

**진단항목 01. 입력값을 페이지 이동 URL로 직접 사용하는 프로그램 설계 시 오픈 리다이렉트가 발생하지 않도록 설계되어 있는가?**

| 진단방법 | 관련 산출물 |
|---|---|
| 1-1 요구사항정의서 대책 + 아키텍처설계서 적용계획 + 요구사항추적표 추적 가능 여부 | 요구사항정의서, 요구사항추적표, 아키텍처설계서 |
| 1-2 이동이 허용된 도메인/주소 목록 정의 | 클래스설계서 |
| 1-3 허용목록을 이용한 입력값 검증 방법·모듈 설계 | 클래스설계서, 개발가이드 |

**진단항목 02. 오픈 리다이렉트 취약점을 점검하는 테스트 계획이 수립되어 있는가?**

| 진단방법 | 관련 산출물 |
|---|---|
| 2-1 임의 URL 주소로 의도된 페이지 리다이렉트 여부 점검 | 단위테스트케이스 |

**관련 산출물**: 요구사항정의서, 요구사항추적표, 아키텍처설계서, 개발가이드, 단위테스트케이스 등

## 시험 포인트

- 관련 보안약점: **HTTP 응답분할**, **신뢰되지 않는 URL주소로 자동접속 연결(오픈 리다이렉트)**
- 응답헤더 삽입 외부입력값은 `\r\n`(CR, LF) 개행문자를 반드시 제거
- 응답헤더에 값을 쓰는 함수 예: **setHeader, addCookie, sendRedirect**
- 오픈 리다이렉트 방지: 허용 URL 목록(하드코딩/설정파일)의 **선택자**로만 사용
- 테스트: 응답분할은 CR/LF 포함 입력값, 오픈 리다이렉트는 임의 URL 주소로 점검
