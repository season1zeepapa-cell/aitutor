# 정수형 오버플로우

- **unit_code**: COURSE-IMP-IV-14
- **단원**: Ⅴ. 구현 단계 보안약점 진단 > 입력데이터 검증 및 표현
- **출처**: 2025년 SW보안약점 진단원 기본(양성)과정 (pp. 360-362)
- **관련 보안약점**: 입력 데이터 검증 및 표현 > 정수형 오버플로우

## 요약

사용자 입력값을 정수형으로 사용할 때 입력값의 크기를 검증하지 않을 경우 발생한다. 정수값이 증가하면서 허용된 가장 큰 값보다 더 커져서 실제 저장되는 값은 아주 작은 수이거나 음수가 되는 현상이다.

## 공격 영향

- 사용자 입력값이 **반복문 제어, 메모리 할당, 메모리 복사** 등의 조건으로 사용되는 경우, 정수형 오버플로우가 발생하면 시스템 오류 발생, 임의 명령 실행, 시스템 점령 등의 보안상 문제를 유발한다.

## 보안대책

1. 언어, 플랫폼 별 **정수 타입의 범위**를 확인하여 사용한다.
2. 정수형 변수를 연산에 사용하는 경우 **결과값의 범위를 체크**한다.
3. 외부입력값을 동적으로 할당하여 사용하는 경우 변수의 값 범위를 검사하여 적절한 범위 내인지 확인한다.

## 진단 흐름도

- 변수로 크기를 동적 결정할 때 외부입력값을 변수로 사용하지 않으면 → **안전**
- 외부입력값을 사용하는 경우, 입력값 범위 확인 → 안전, 아니면 **위험**

## 안전한 코드 (입력값 범위 검증)

```java
String tmp = StringUtil.isNullTrim(request.getParameter("slf_msg_param_num"));
if (tmp.equals("0")) {
    msg_str = PropertyUtil.getValue(msg_id);
} else {
    try {
        int param_ct = Integer.parseInt(tmp);
        // 외부 입력값을 정수형으로 사용할 때 입력값의 크기를 검증하고 사용
        if (param_ct < 0) {
            throw new Exception();
        }
        String[] strArr = new String[param_ct];
    } catch (Exception e) {
        msg_str = "잘못된 입력(접근) 입니다.";
    }
}
```

## 시험 포인트

- 정수형 오버플로우: 입력값 크기 미검증 시 최대값 초과로 작은 수·음수가 저장되는 현상
- 위험 맥락: 반복문 제어, 메모리 할당, 메모리 복사 조건 → 시스템 오류·임의 명령 실행·시스템 점령
- 보안대책: 정수 타입 범위 확인 / 연산 결과값 범위 체크 / 동적 할당 값 범위 검사
- 안전한 코드: Integer.parseInt 후 음수 등 범위 검증(`param_ct < 0` → 예외) 후 배열 크기로 사용
