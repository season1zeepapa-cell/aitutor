# 암호키 관리 (COURSE-DSG-SF-05)

- 단원: Ⅳ. 분석·설계 단계 보안약점 진단 — 보안기능
- 출처: 2025년 SW보안약점 진단원 기본(양성)과정, pp.209-218
- 관련 라이브러리: DSG-SF-05
- 관련 보안약점: (보안기능) 하드코드된 중요정보, 주석문 안에 포함된 시스템 주요 정보

## 개요
암호키 생성·분배·접근·파기 등 안전하게 암호키 생명주기를 관리할 수 있는 방법을 설계해야 한다.

- DB 데이터 암호화에 사용되는 암호키는 KISA 「암호 알고리즘 및 키 길이 이용 안내서」에서 정의하는 방법을 적용해야 한다.
- 설정파일(xml, Properties) 내의 중요정보 암호화에 사용되는 암호키는 암호화해서 별도의 디렉터리에 보관해야 한다.

## 설계 시 고려사항

### 1. 암호키 관리 규칙 생성 시 고려사항
- DB 데이터 암호화 암호키는 데이터가 저장되는 데이터베이스와 물리적으로 분리된 장소에 별도 보관.
- 암호키 생성·분배·사용·폐기의 생명주기 관리를 위한 명시적 암호화 정책 적용.
- 패스워드·암호키는 메모리에 저장하지 않으며, 부득이 저장 시 사용종료 후 메모리를 0으로 초기화.
- 암호키 생성 및 변경 시 백업기능 구현.
- 사용기간: 대칭키 비밀키 송신자 최대 2년, 수신자 (송신자 사용기간+3년) 이하 / 공개키 암호화 공개키 최대 2년, 복호화 개인키 최대 2년, 검증용 공개키 1~3년, 서명용 개인키는 키 크기에 따라 다름.

### 2. 암호키 관리 수준 지정 (FIPS 140-3)
| 레벨 | 내용 |
| --- | --- |
| Level 1 | 암호모듈 기본 보안요구사항만 충족, 최소한의 보안 제공 |
| Level 2 | 불법 접근 방지 + 침입 후 변조 증거 제공으로 물리적 보안 메커니즘 제공(tamper-evident coatings, seals) |
| Level 3 | 강력한 변조 탐지·대응, 침입 감지 시 저장된 키 삭제 |
| Level 4 | 암호모듈 외부 전압·온도 등 환경 이상 변화 시 암호키 삭제 |

- FIPS PUB 140-3은 2022년 4월 1일부터 새로운 제출에 대해 FIPS 140-2를 대체. (참고: FIPS 140-2 인증은 검증 후 5년 유효)

### 3. 키 생명주기 관리 프로세스 / 키 복구 / 유효기간
- 키 생성: 생성·사용·관리 주체와 생성 프로그램·방법·절차 명시.
- 키 사용: 사용 방법·절차, 키 종류별 변경주기, 인가 사용자만 접근하는 접근통제 방법·요구사항 명시.
- 키 폐기: 사용주기 만료·용도 종료 등 폐기 경우와 안전한 폐기 절차·요구사항 명시.
- 키 복구: 퇴사 등으로 사용자 이외 복구가 필요한 경우 암호화 키는 정보보호담당자 관리 하 암호키 관리대장 등에서 복구, 패스워드는 정보보호담당자가 임시 패스워드 발급.
- 사용 유효기간 경과 시 사용자 인터페이스로 알리고 새 키 생성 권장.

### 4. 설정파일 내 중요정보 암호화 키 보관
- 설정파일 내 중요정보 암호화에 사용된 암호키는 마스터키로 암호화하여 별도 디렉터리에 보관.

## 진단 기준 및 방법

### 요구사항 01 — DB 데이터 암호화 암호키 관리
- 암호키 관리 프로세스 구축, 암호화 데이터 DB와 물리적 분리 보관, 암호키 관리수준 정의, 생성·변경 방법·백업정책 정의
- 사용기간 정의 및 경과 시 대응방법 정의(대칭키·비대칭키 기간), 사용종료 후 메모리 0 초기화 코딩규칙(개발가이드)
- 암호키 외부 유출 점검 테스트 계획

### 요구사항 02 — 설정파일 내 중요정보 암호화 키 보관
- 설정파일(properties, xml)에 저장되는 중요정보(DB계정정보, 시스템 중요정보 등) 암호화 저장, 암·복호화 키를 설정파일과 별도 위치 저장
- 설정파일 중요정보 암호화 저장·암호키 안전 위치 점검 테스트 계획

> 모든 요구사항의 1-1 진단방법은 공통: 요구사항정의서 대책 + 아키텍처설계서 적용계획 + 요구사항추적표 추적 가능 여부 확인.

## 시험 포인트
- DB 암호화 암호키는 데이터 저장 DB와 물리적으로 분리된 장소에 별도 보관.
- 암호키 사용기간: 대칭키 비밀키 송신자 최대 2년·수신자 (송신자+3년) 이하, 암호화 공개키/복호화 개인키 최대 2년, 검증용 공개키 1~3년, 서명용 개인키는 키 크기에 따라 다름.
- FIPS 140-3 Level 1~4: Level 3은 침입 감지 시 키 삭제, Level 4는 전압·온도 등 환경 이상 시 키 삭제.
- 패스워드·암호키는 메모리 미저장, 부득이 저장 시 사용종료 후 메모리 0 초기화.
- 설정파일 내 중요정보 암호키는 마스터키로 암호화하여 별도 디렉터리에 보관, 암·복호화 키는 설정파일과 별도 위치.
- 관련 보안약점: 하드코드된 중요정보, 주석문 안에 포함된 시스템 주요 정보.
