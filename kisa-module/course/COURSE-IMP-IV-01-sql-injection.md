## 요약

데이터베이스(DB)와 연동하는 웹 애플리케이션에서 입력된 데이터에 대한 유효성 검증을 하지 않고 입력값을 DB 쿼리 일부로 사용하는 경우 발생하는 보안약점이다. 인증 우회, 권한 없는 사용자의 DB 데이터 유출·수정·삭제, 저장 프로시저를 통한 원격 시스템 명령어 수행이 가능하다. 정적 쿼리 사용을 원칙으로 하고, 불가피한 동적 쿼리에는 입력값 검증을 적용한다.

## 개요 — 정의와 영향

- **정의**: DB와 연동하는 웹 애플리케이션에서 입력 데이터에 대한 유효성 검증 없이 입력값을 DB 쿼리의 일부로 사용하는 경우 발생한다.
- **영향 ①**: 인증을 우회해서 시스템에 로그인할 수 있다.
- **영향 ②**: 조작된 쿼리를 이용해 권한 없는 사용자가 DB 데이터를 유출하거나 수정·삭제할 수 있다.
- **영향 ③**: 저장 프로시저(stored procedure)를 호출하여 원격으로 시스템 명령어를 수행할 수 있다.

## 보안대책

- 정적 쿼리를 사용하여 쿼리문의 구조가 바뀌지 않도록 한다.
- 동적 쿼리를 사용해야 하는 경우, 입력값에 쿼리문의 구조를 변경할 수 있는 문자열을 검사한 후 쿼리문 생성에 사용한다.
- 웹 애플리케이션에서 사용하는 데이터베이스 사용자 권한을 최소화한다.
- Internal Error(500) 오류 정보가 노출되지 않도록 한다.
- **진단 흐름**: 동적 쿼리 실행 시 PreparedStatement 사용이면 안전, 미사용 상태에서 외부입력값을 사용하고 필터링 모듈이 없으면 위험으로 판정한다.

## 코드 예제 핵심 — JDBC / MyBatis / Hibernate

- **JDBC**: 외부입력값(gubun)을 문자열 결합으로 쿼리에 넣으면 `' or 1=1; delete * from board; --` 같은 삽입이 가능하여 위험하다. → `PreparedStatement`에 `?` 플레이스홀더와 `setString()`으로 바인딩하면 안전하다.
- **MyBatis**: `${변수}`는 외부 입력값을 문자열 결합 형태로 쿼리에 반영하므로 안전하지 않다. → `#{변수}`를 사용하여 변수가 쿼리맵에 바인딩되도록 수정하는 것이 안전하다.
- **MyBatis LIKE 검색**: `like '%${keyword}%'`는 위험. → `like '%'||#{keyword}||'%'`로 바인딩 변수와 문자열 연결을 사용한다.
- **Hibernate**: `createQuery`에 `'" + name + "'` 결합은 위험. → `?` 위치 파라미터 + `query.setString()`, 또는 `:name` 명명 파라미터 + `query.setParameter()`를 사용한다.

## 핵심 개념

| 용어 | 정의 |
| --- | --- |
| 정적 쿼리(Static Query) | 외부입력값에 의해 쿼리문의 구조가 바뀌지 않는 쿼리. SQL 삽입 방어의 기본 원칙 |
| PreparedStatement | JDBC에서 `?` 플레이스홀더에 `setString()` 등으로 값을 바인딩하여 쿼리 구조 변경을 막는 정적 쿼리 API |
| MyBatis #{} vs ${} | `#{}`는 바인딩 변수로 안전, `${}`는 문자열 결합으로 쿼리에 반영되어 SQL 삽입에 취약 |
| 최소권한 DB 계정 | 웹 애플리케이션이 사용하는 DB 사용자 권한을 최소화하여 침해 시 피해 범위를 줄이는 대책 |

## 시험 포인트

- SQL 삽입은 입력값 유효성 검증 없이 입력값을 DB 쿼리 일부로 사용할 때 발생한다.
- 영향: 인증 우회 로그인 / 권한 없는 데이터 유출·수정·삭제 / 저장 프로시저를 통한 원격 시스템 명령어 수행
- 보안대책 4가지: 정적 쿼리 사용 / 동적 쿼리 시 입력값 문자열 검사 / DB 사용자 권한 최소화 / Internal Error(500) 정보 미노출
- JDBC는 PreparedStatement + `?` 바인딩, MyBatis는 `${}` 대신 `#{}`, Hibernate는 `?` 또는 `:name` 파라미터 사용이 안전한 코드
- MyBatis LIKE 검색의 안전한 형태는 `like '%'||#{keyword}||'%'`
