# COURSE-02 · Ⅱ. SW개발 관련 법률과 제도의 이해

> **유형** 교육자료 (양성과정 교재) · **출처** 2025년 SW보안약점 진단원 기본(양성)과정 (p.37–44)

## 개요

공공(행정안전부·**전자정부법**)과 민간(과학기술정보통신부·**소프트웨어 진흥법**)의 SW개발보안 법규를 비교하고, 행정기관 등에 적용되는 보안약점 진단 제도(**대상·범위·기준**), 추진 체계, 활동주체별 역할을 학습한다.

## 1. 민간 SW개발보안 법규 – 소프트웨어 진흥법

- **제29조(소프트웨어개발보안 진흥)**: 과기정통부장관이 진흥 사업 추진
  - 기술연구·인력 양성 등 기반 조성
  - 중소기업 SW사업자의 SW개발보안 활성화 지원
  - 그 밖에 대통령령으로 정하는 사업
- **시행령 제27조** 대통령령 사업: 법·제도 조사·연구 / 실태조사·국제협력 / 보안약점 진단·기술지원 / 정보 축적·활용 / 참고기준 마련·보급 / 이행 점검

> 📌 시험: 민간 = 과기정통부 = SW진흥법(제29조) 매핑

## 2. 공공 vs 민간 SW개발보안 법 비교

| 구분 | 공공·행정기관 | 민간 |
|------|-------------|------|
| **소관부처** | 행정안전부 | 과학기술정보통신부 |
| **근거법** | 전자정부법 | 소프트웨어 진흥법 |
| **활동** | 전자정부 SW 보안약점 진단, 모바일 앱 보안성 검증, 가이드 개발·배포, 진단원 양성, 인식제고(교육·컨퍼런스·경진대회) | SW개발보안 규정, 기반조성·인력양성, 중소기업 지원, 시행령 사업 |

- 전자정부법에 개발보안 법적 근거를 마련하고 **SW 보안약점 진단원 제도를 명시**하여 국가 전문 자격으로 개선 계획

## 3. 행정기관 등에 적용되는 SW개발보안 제도 – 대상·범위·기준

> 행정기관 등이 정보화 사업 추진 시, SW 보안약점이 없도록 SW를 개발 또는 변경

| 구분 | 내용 | 근거 |
|------|------|------|
| **대상** | 감리대상 정보시스템 사업 (※ 감리대상 外도 자체 적용) | 전자정부법 시행령 제71조 제1항 |
| **범위** | 신규개발=설계 산출물+소스코드 전체 / 유지보수=변경된 부분 (※ **상용 SW 제외**) | 구축·운영 지침 제50조 |
| **기준** | **설계단계 20개 항목** + **구현단계 49개 항목** (※ 감리기준 세부검사항목 포함) | 구축·운영 지침 제52·53조 |

**기타 사항**
- 제안요청서에 '소프트웨어 개발보안 적용' 명시 (제16·51조)
- 진단도구는 **국가보안기술연구소장 인증(CC인증, 국정원)** 도구 사용 ('14.1월부터)
- 감리법인은 진단 시 **진단원을 우선적으로 배치**

## 4. 추진 체계와 활동주체별 역할

**추진 체계**: 행정안전부(정책) → 한국인터넷진흥원(전문기관) → 행정기관 등(발주기관) → 사업자(개발)/감리법인(진단)

| 주체 | 역할 |
|------|------|
| **행정안전부** | 법·제도 개선, 가이드 배포, **진단원 자격 부여** |
| **한국인터넷진흥원(KISA)** | 정책·기술 지원, 가이드 개발, **교육과정·자격제도 운영** |
| **발주기관** | 개발보안 계획 수립, 제안요청서 명시, 사업자 준수 점검, 진단 의뢰, 최종 확인 |
| **사업자(개발자)** | 가이드 참조 개발, 자체 진단·제거, 시정요구 이행, 결과물·증빙 제출 |
| **감리법인** | 설계항목 반영 확인, 보안약점 제거 진단, CC인증 도구 사용, **진단원 우선 배치** |

## 🎯 시험 출제 포인트

1. 민간=과기정통부=소프트웨어 진흥법 제29조 / 공공=행정안전부=전자정부법
2. 진단 대상 = 감리대상 정보시스템 사업 (전자정부법 시행령 제71조 제1항)
3. 진단 범위: 신규=설계 산출물+소스코드 전체, 유지보수=변경분, **상용 SW 제외**
4. 진단 기준: 설계단계 **20개** + 구현단계 **49개** 항목 (구축·운영 지침 제52·53조)
5. 진단도구 = 국가보안기술연구소장 인증(CC인증) 도구
6. 주체별 역할: 행안부=진단원 자격 부여, KISA=교육·자격제도 운영, 감리법인=진단원 배치
