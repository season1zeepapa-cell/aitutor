# 메모리 버퍼 오버플로우

- **unit_code**: COURSE-IMP-IV-16
- **단원**: Ⅴ. 구현 단계 보안약점 진단 > 입력데이터 검증 및 표현
- **출처**: 2025년 SW보안약점 진단원 기본(양성)과정 (pp. 366-368)
- **관련 보안약점**: 입력 데이터 검증 및 표현 > 메모리 버퍼 오버플로우

## 요약

버퍼를 이용하여 메모리를 사용할 때, 버퍼의 크기보다 큰 데이터를 버퍼에 기록하는 경우 버퍼의 경계를 넘어 다른 메모리 영역을 침범하게 되는 경우 발생한다.

## 공격 영향

- 메모리 상의 중요한 정보를 읽거나, 시스템 충돌을 발생시키거나, **리턴 주소를 조작하여 임의의 코드가 실행**되도록 조작할 수 있다.

## 보안대책

1. 버퍼의 범위를 넘어 데이터를 접근하지 못하도록 **버퍼의 크기와 인덱스 값을 정확하게** 사용한다.
2. 외부 입력값을 기준으로 버퍼나 기록 데이터의 크기를 결정할 경우 그 값이 **타당한지 검사**한 후 사용한다.
3. 문자열 저장을 위해 메모리 버퍼를 사용하는 경우 **널(NULL) 문자로 종료**한다.

## 진단 흐름도

- 버퍼 사용 확인 → 값의 크기 ≤ 버퍼크기 (아니면 **위험**)
- 인덱스 ≥ 0 (아니면 **위험**)
- 문자열 처리인 경우 NULL 문자로 종료 → 모두 만족하면 **안전**

## 안전한 코드 (버퍼 크기·NULL 종료)

```c
typedef struct _charvoid {
   char x[16];
   void * y;
   void * z;
} charvoid;

static void goodCode() {
   charvoid cv_struct;
   cv_struct.y = (void *) SRC_STR;
   printLine((char *) cv_struct.y);
   /* sizeof(cv_struct.x)로 변경하여 포인터 y의 덮어쓰기를 방지함 */
   memcpy(cv_struct.x, SRC_STR, sizeof(cv_struct.x));
   /* 문자열 종료를 위해 널 문자를 삽입함 */
   cv_struct.x[(sizeof(cv_struct.x)/sizeof(char))-1] = '\0';
   printLine((char *) cv_struct.x);
   printLine((char *) cv_struct.y);
}
```

> 안전하지 않은 코드는 `memcpy(cv_struct.x, SRC_STR, sizeof(cv_struct));` 처럼 구조체 전체 크기를 복사하여 `char x[16]` 경계를 넘어 포인터 y에 덮어쓰기가 발생한다.

## 시험 포인트

- 메모리 버퍼 오버플로우: 버퍼 크기보다 큰 데이터 기록 시 경계를 넘어 인접 메모리 침범
- 공격 영향: 중요 정보 읽기·시스템 충돌·리턴 주소 조작으로 임의 코드 실행
- 보안대책: 버퍼 크기·인덱스 정확 사용 / 입력값 기준 크기 결정 시 타당성 검사 / 문자열은 NULL 문자 종료
- 안전한 코드: `sizeof(cv_struct)` 대신 `sizeof(cv_struct.x)`로 복사하고 끝에 `'\0'` 삽입
- 진단: 값 크기 ≤ 버퍼크기, 인덱스 ≥ 0, 문자열은 NULL 종료 모두 만족 시 안전
