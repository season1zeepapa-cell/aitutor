# 보안기능 입력값 검증 (COURSE-DSG-IV-09)

> Ⅳ. 분석·설계 단계 보안약점 진단 · 2025년 SW보안약점 진단원 기본(양성)과정 · pp.151-158
> 관련 라이브러리: DSG-IV-09 · 분류: 입력데이터 검증 및 표현

## 개요

보안기능(인증, 인가, 권한부여 등) 프로그램 동작을 위해 사용되는 입력값과 함수(메소드)의 외부입력값 및 수행결과에 대한 처리방법을 설계한다.

- 사용자의 역할·권한을 결정하는 정보는 **서버에서 관리**
- 쿠키값·환경변수·파라미터값 등 외부입력값이 보안기능 함수의 인자로 사용되는 경우, **검증 후 제한적으로 사용**
- 중요 상태정보·인증·권한결정 정보는 **쿠키로 전송하지 않으며**, 불가피하면 **암호화**해서 전송
- 관련 보안약점: 입력데이터 검증 및 표현 > **보안기능 결정에 사용되는 부적절한 입력값, 정수형 오버플로우** / 코드 오류 > **Null Pointer 역참조**

## 설계 시 고려사항

- 상태정보·인증·인가·권한 관련 중요정보는 **서버 측 세션이나 DB**에 저장해서 사용하도록 설계한다.
- 보안기능 수행 함수는 **외부입력값에 의존할 필요가 없는 구조**로 설계하고, 외부입력(쿠키·환경변수·파라미터)을 받아야 하면 **검증 후 제한적으로 사용**한다.
- 외부입력값은 사용 전 **NULL 여부를 체크**하고, 출력 함수에서 포맷 지정값으로 사용되면 취약점(포맷스트링)이 발생할 수 있으므로 주의한다.
- 입력값 검증은 **클라이언트 측과 서버 측 검증방식이 동일**해야 한다.
- 중요정보가 포함되는 쿠키는 암호화하여 전송하거나 **HMAC**(Hash-based Message Authentication Code)을 이용해 서버 측에서 무결성을 검증한다.

## 진단 기준 및 방법

### 요구사항 01 — 역할·권한 결정 정보 서버 관리

**진단항목 01. 사용자 역할·권한 결정을 서버 관리 정보로 서버에서 처리하도록 설계되어 있는가?**

| 진단방법 | 관련 산출물 |
|---|---|
| 1-1 요구사항정의서 대책 + 아키텍처설계서 적용계획 + 요구사항추적표 추적 가능 여부 | 요구사항정의서, 요구사항추적표, 아키텍처설계서 |
| 1-2 사용자 역할 구분(일반사용자·관리자·최고관리자 등) | 클래스설계서, DB설계서 |
| 1-3 각 역할에 대한 권한 구분 | 클래스설계서, DB설계서 |
| 1-4 역할·권한 정의·저장 DB 설계 | DB설계서 |
| 1-5 역할·권한 검증 모듈 설계 또는 외부 라이브러리 사용 시 검증정보가 DB·세션에 저장 | 클래스설계서, 유즈케이스설계서 |

**진단항목 02. 인증우회 및 권한상승 가능 여부를 점검하는 테스트 계획이 수립되어 있는가?**

| 진단방법 | 관련 산출물 |
|---|---|
| 2-1 조작된 파라미터·쿠키로 역할/권한 체크 우회 여부 점검 | 단위테스트케이스 |

### 요구사항 02 — 외부입력값 검증 후 제한적 사용

**진단항목 01. 보안기능 수행에 사용되는 입력값이 안전하게 사용되도록 설계되어 있는가?**

| 진단방법 | 관련 산출물 |
|---|---|
| 1-1 요구사항정의서 대책 + 아키텍처설계서 적용계획 + 요구사항추적표 추적 가능 여부 | 요구사항정의서, 요구사항추적표, 아키텍처설계서 |
| 1-2 보안기능에 사용되는 값의 종류·출처·의미 정의 | 유즈케이스설계서, 클래스설계서 |
| 1-3 외부입력값 사용 시 타당한 근거/사유 명시 | 유즈케이스설계서, 클래스설계서 |
| 1-4 외부입력값 검증 방법 정의 (NULL 검사, 정수 오버플로우 등 값 범위 초과 점검) | 개발가이드 |

**진단항목 02. 외부입력값 조작을 통한 보안기능 우회 여부를 점검하는 테스트 계획이 수립되어 있는가?**

| 진단방법 | 관련 산출물 |

### 요구사항 03 — 인증·권한결정 정보 쿠키 전송 통제

**진단항목 01. 쿠키로 전달되는 정보 중 불가피한 중요정보가 안전하게 전달되도록 설계되어 있는가?**

**진단항목 02. 쿠키 조작을 통한 중요정보 탈취·변조 여부를 점검하는 테스트 계획이 수립되어 있는가?**

## 시험 포인트

- 관련 보안약점: **보안기능 결정에 사용되는 부적절한 입력값, 정수형 오버플로우, Null Pointer 역참조**
- 역할·권한 등 중요정보는 **서버 측 세션/DB**에서 관리
- 보안기능 함수는 외부입력 의존 없는 구조, 불가피하면 **검증 후 제한적 사용**
- 외부입력값은 **NULL 검사** 필수, 출력 함수 포맷 지정값 사용 주의
- **클라이언트와 서버의 입력값 검증방식이 동일**해야 함
- 중요정보 쿠키는 **암호화 전송 또는 HMAC**으로 무결성 검증
