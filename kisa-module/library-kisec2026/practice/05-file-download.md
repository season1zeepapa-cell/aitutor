# 실습 05 — 파일을 다운로드하는 기능에 대한 설계단계 보안약점 진단

> 출처: KISEC 2026 기본과정 교재 p314–316 (Ⅳ-02 보안설계 기준 및 설계 기준 실습)

## ✅ 채운 양식 — 보안 설계 기준

| 구분 | 보안 설계 기준 | 중점점검항목 | 비고 |
|------|--------------|------------|------|
| 입력데이터 검증 및 표현 | **업로드·다운로드 파일 검증** (DSG-IV-10) | 다운로드 요청 파일명에 경로조작 문자(`..`, `/`, `\`)를 제거·필터링하는 설계, 허가된 사용자·파일인지 확인하는 다운로드 컨트롤러 설계, 화이트리스트(허용 파일 목록) 범위 안에서만 접근하도록 설계 | 경로조작·임의 파일 다운로드 방지 |
| 입력데이터 검증 및 표현 | **HTTP 프로토콜 유효성 검증** (DSG-IV-07) | 첨부파일 클릭 시 이동하는 다운로드 URL을 외부입력값으로 사용하는 경우, 시스템이 허용한 URL 목록의 선택자로만 사용하도록 검증 설계 | 신뢰되지 않은 URL 자동연결 방지 |
| 보안기능 | **중요자원 접근통제** (DSG-SF-04) | 첨부파일(중요자원)에 대해 다운로드 권한이 있는 사용자만 접근하도록 ACL·RBAC 기반 접근통제 정책 설계, 최소권한 원칙 적용 | 인가되지 않은 파일 다운로드 차단 |
| 입력데이터 검증 및 표현 | **업로드·다운로드 파일 검증 — 무결성 검사** (DSG-IV-10 ④) | 다운로드 받는 파일이 소스코드·실행파일인 경우 체크섬(해시값)을 함께 내려받아 무결성 검사 후 사용하도록 설계 | 다운로드 파일 변조 탐지 |

## 💡 진단 해설

이 화면은 **첨부파일 클릭 → 다운로드 URL 이동 → 파일 내려받기**의 단일 흐름이지만, 다운로드는 "어떤 파일을, 누구에게" 제공하느냐가 핵심이라 입력데이터 검증과 보안기능이 함께 적용된다.

### 1. 업로드·다운로드 파일 검증 (DSG-IV-10) — 핵심
- **왜 적용되는가**: 다운로드 요청에 파일명/경로가 외부입력값으로 전달되면, 공격자가 `../../etc/passwd` 같은 경로조작 문자열을 넣어 의도하지 않은 시스템 파일을 내려받을 수 있다(경로조작·디렉터리 탐색). 또한 게시물 식별자나 파일 식별자를 변조해 본인 것이 아닌 파일을 받는 임의 다운로드도 가능하다.
- **설계단계 진단방법**: 다운로드 요청 파일명 검증 설계가 **요구사항정의서**에 대책으로 수립되고 **아키텍처설계서**에 적용계획이 반영되어 **요구사항추적표**로 추적 가능한지 확인한다. 구체적인 검증 로직(경로조작 문자 제거, 허가 파일 확인)은 **유즈케이스명세서·클래스설계서·DB설계서**를 검토하고, 검증 동작 점검은 **단위테스트케이스**를 검토한다.
- **결함 포인트**: 파일명에 대한 경로조작 문자(`..`, `/`, `\`) 필터링 설계가 없거나, 다운로드 대상이 화이트리스트로 제한되지 않고 사용자 입력 경로를 그대로 신뢰하는 경우.

### 2. HTTP 프로토콜 유효성 검증 (DSG-IV-07)
- **왜 적용되는가**: 첨부파일 클릭 시 "다운로드 URL로 이동"하는 처리가 있다. 이동 대상 URL이 외부입력값(파라미터)으로 결정된다면, 신뢰되지 않은 외부 URL로 리다이렉트되어 악성 파일 다운로드나 피싱으로 이어질 수 있다.
- **설계단계 진단방법**: 페이지 이동(리다이렉트/포워드)용 URL을 허용된 URL 목록의 선택자로만 사용하도록 설계되었는지 **요구사항정의서·아키텍처설계서**와 **개발가이드**(코딩규칙)에서 확인한다.
- **결함 포인트**: 다운로드 URL을 입력 파라미터 값 그대로 사용해 임의 URL 자동연결이 가능한 경우.

### 3. 중요자원 접근통제 (DSG-SF-04)
- **왜 적용되는가**: 공지사항 첨부파일이 비공개·권한 제한 자료일 수 있다. 다운로드 링크만 알면 누구나 받을 수 있다면 인가되지 않은 사용자가 중요자원에 접근하게 된다.
- **설계단계 진단방법**: 첨부파일이라는 중요자원에 대한 접근통제 정책(최소권한·RBAC)이 **요구사항정의서·아키텍처설계서**에 수립되었는지 확인하고, 우회 점검은 **단위테스트케이스**를 검토한다.
- **결함 포인트**: 다운로드 컨트롤러가 요청자의 권한을 검사하지 않고 파일을 제공하는 경우(접근통제 누락).

### 4. 무결성 검사 (DSG-IV-10 ④)
- 다운로드 대상이 실행파일·소스코드라면 체크섬을 함께 제공해 무결성 검사 후 사용하도록 설계되었는지 점검한다. 일반 첨부 문서만 다루는 화면이라면 적용도가 낮으나, 다운로드 기능의 일반 기준으로 함께 검토한다.
