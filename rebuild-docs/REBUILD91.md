# REBUILD91 — KISA 온보딩 가이드 v5 갱신

> 2026-07-04. 선행: REBUILD84~90 (오늘 개편 전체 반영).

## §1. 배경

온보딩(TutorialOverlay) KISA 트랙이 v4(2026-04-25, mcq 3유형 286문항 시대) 기준으로 낡음.
오늘의 대개편(mcq 폐지·6유형 체계·라이브러리 학습 모드·모의시험 신구성)을 반영해 v5 로 전면 갱신.

## §2. 갱신 내용

- **버전 v4 → v5** — 기존 사용자에게 가이드 재안내(localStorage 키 불일치 시 자동 표시).
- 트랙 선택 카드: "148문항 + 69챕터" → "6유형 2,852문항 · 69챕터 · 5문서 라이브러리".
- 소개: 3유형 286문항 → 6유형 2,852문항 + 지식 라이브러리 5종.
- "3종 드릴 모드" → **"6가지 문제 유형"** (객관식 562 · 단순서술형 562 · 단답형 138 · 진단 138 · 복합 93 · 코드식별 1,359, 실측 수치).
- **신규 스텝 "💾 예시코드 라이브러리 = 조회 + 학습"** — 읽기 진도·이어보기·🎓 블라인드 판별 1,359장·헷갈림→복습 등록 (REBUILD86~87).
- 해설 스텝: "🎯 MCQ" → 객관식·코드식별/단답형/실기·서술형(rubric) 3계열로 재정리.
- 모의고사: 이론 60분(객관식 20+단답형 10) / 실기 100분(진단 13+복합 2+코드식별 5) / 전체 180분 50문항 (REBUILD84 구성).
- SRS 스텝에 **오답 노트**(70점 미만 수집·약점 재풀이) 합류, 완료 스텝에 추천 학습 순서 추가.
- 학습 자료 스텝에 챕터 하단 드릴 진입(객관식·단답형·코드식별) 언급.
