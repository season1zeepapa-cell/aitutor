# REBUILD93 — 블라인드 판별 학습 모드 UX 개선 3종 (+칩 전환 버그 수정)

> 2026-07-04. 선행: REBUILD92(코드 그룹 아코디언). 사용자 요청 "블라인드 모드 UI 점검" → 제안 1~3 승인.

## §1. 개선 내용

1. **☰ 약점 목차 점프 시트** — 헤더 약점명(또는 ☰ 목차 칩) 탭 → 바텀시트.
   - 카테고리 아코디언(현재 카드의 분류는 펼친 채 열림) → 약점 행 탭 시 그 약점 첫 카드로 점프.
   - 약점별 `n장` / 판별 시작 후엔 `done/n 판별` 진도 표시. 현재 약점은 하이라이트.
   - 진도 데이터: 카드별 판별 기록을 localStorage `kisa-codelib-blind-judged-v1` ({source:{cardId:correct}})에 적재 — 향후 "오답만 다시" 재료로도 사용 가능.
2. **판정 배너 자동 스크롤** — 긴 코드에서 [취약/안전] 판정 시 결과 배너가 화면 밖에 생기던 문제 → 배너 ref 로 scrollIntoView.
3. **이어하기 안내 배지** — 저장 위치(>0)에서 세션 진입 시 "▶ N번째 카드부터 이어서" 배지 + [처음부터] 버튼. 점프·재시작하면 자동 숨김.

## §2. 버그 수정 (점검 중 발견)

- **출처 칩 전환 시 세션 미리마운트**: `<BlindSession source=...>` 가 key 없이 렌더되어 칩을 바꿔도
  이전 출처의 idx·판정 상태가 남았다(범위 체크로 크래시는 없었지만 위치가 어긋남). → `key={active.id}` 로 출처별 리마운트.
