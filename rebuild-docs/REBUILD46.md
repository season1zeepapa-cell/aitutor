## §1. 재점검 — 예시코드가 빠져 있었다

`build-kisa-library.mjs` 가 `code_examples` 를 **개수만** 합본에 넣고 본문을 버렸다("상세는 원문"). 앱에서 코드를 볼 수 없었음.

**개선**: 합본 카드에 실제 코드 포함.
- `codeExamples: [{ lang, vulnerable, safe, note }]`
- `diagnosisCode: { truePositive[{desc,code}], falsePositive[{desc,code}] }`
- LibraryFab 에 `CodeBlock`(❌취약=빨강 / ✅안전=초록) + `CodeSection` 추가 → 언어별 취약/안전 코드, note 해설, 정탐/오탐 코드 렌더.
- 합본 240KB → 471KB, 청크 485KB (lazy 분리라 초기 번들 무영향).

---

## §2. 가이드 순서 정렬

`build-kisa-library.mjs` 가 각 카드에 정렬 메타 부여 후 정렬:
- **단계**: 설계(design) → 구현(implementation)
- **분류**: 입력검증 → 보안기능 → 시간및상태 → 에러처리 → 코드오류 → 캡슐화 → API오용 → 세션통제 (붙임3)
- **항목**: 분류 안에서 번호순
- **교재**: 단원 Ⅰ→Ⅵ, Ⅳ·Ⅴ 는 분류로 세분
- `order = stage*100000 + cat*1000 + num` 로 안정 정렬.

---

## §3. 2단계 아코디언 (공간 효율)

- 계층: 자료원 → **g1(단계/단원)** → **g2(분류)** → 항목
- `g1`/`g2` 메타로 중첩 그룹핑 (Map 삽입순 = 정렬순 유지).
- 단원카드(Ⅰ·Ⅱ·Ⅲ·Ⅵ)는 g2 없이 단원 직속, Ⅳ·Ⅴ 와 진단가이드는 분류 단계 추가.
- 기본 접힘 → 필요한 분류만 펼침. 검색 시에는 평면 결과.
- 새 자료원은 `sources` 추가만으로 자동 정렬·계층화 (UI 무수정).
